## 基础

#### Java 语言有哪些特点?

面向对象，单继承，跨平台

#### 什么是字节码?采用字节码的好处是什么?

给jvm去执行的指令集合，好处是可以解决跨平台问题

#### 为什么说 Java 语言“编译与解释并存”？

源码到字节码是编译，字节码执行是解释

## 基本语法

#### 字符型常量和字符串常量的区别?

字符型是char，单引号，字符串底层是char数组，双引号

#### 标识符和关键字的区别是什么？

标识符是命名，关键字是解析语法

#### 自增自减运算符

++a是先加再赋值，a++是先赋值再加

#### continue、break 和 return 的区别是什么？

continue是跳出本次循环，break是 跳出循环，return是方法返回

## 方法

#### 什么是方法的返回值?方法有哪几种类型？

返回值是方法执行结果，静态和非静态，有参无参，有无返回值

#### 静态方法为什么不能调用非静态成员?

非静态属于实例

#### 静态方法和实例方法有何不同？

静态可类名和实例调用，实例只可实例调用

#### 重载和重写的区别

重载是方法名相同，参数返回值不同，重写是子类重写父类

### == 和 equals() 的区别

==一般判断引用相等，equals()判断内容相等

### hashCode() 与 equals()

#### hashCode() 有什么用？

返回对象哈希值，哈希值确定对象在哈希表中索引位置

#### 为什么要有 hashCode？

判断对象相等

#### 为什么重写 equals() 时必须重写 hashCode() 方法？

可能内容相同但哈希值不同

#### 什么是可变长参数？

接收更多参数

## 基本数据类型

#### Java 中的几种基本数据类型了解么？

char、short、byte、int、float、double、long、boolean

#### 包装类型的常量池技术了解么？

char缓存0-127，byte、short、int、long缓存 -128到128

#### 自动装箱与拆箱了解吗？原理是什么？

自动装箱是valueOf()，拆箱是对象的xxxValue()方法

## 面向对象基础

#### 面向对象和面向过程的区别

面向对象以对象为基础，通过对象调用方法，面向过程抽取过程为方法，直接调用

#### 成员变量与局部变量的区别有哪些？

成员变量随实例存在，局部变量作用域为代码块内

#### 创建一个对象用什么运算符?对象实体与对象引用有何不同?

new，实体是在内存中，引用是指向这块内存，一个实体可有多个引用

#### 对象的相等与指向他们的引用相等,两者有什么不同?

对象相等是内容相等，引用相等是引用指向的内存地址相等

#### 一个类的构造方法的作用是什么?

初始化实例

#### 如果一个类没有声明构造方法，该程序能正确执行吗?

能，默认无参

#### 构造方法有哪些特点？是否可被 override?

无返回值，只有在new的时候被调用，可重载，不可重写

## 面向对象三大特征

#### 封装

将私有属性封装，通过调用方法访问

#### 继承

子类继承父类属性、方法，实现代码复用

#### 多态

父类引用指向子类实例，编译看引用，调用看实例

#### 接口和抽象类有什么共同点和区别？

内部方法都可能被abstract修饰，抽象类规定类，接口规定行为

#### 深拷贝和浅拷贝区别了解吗？什么是引用拷贝？

浅拷贝是对象直接拷贝，深拷贝是对象内的属性对象也拷贝，引用拷贝是不同引用指向相同实例

## Java 常见对象

#### Object 类的常见方法有哪些？

equals、toString、clone、wait、notify，getClass、hashCode

#### String、StringBuffer、StringBuilder 的区别？String 为什么是不可变的?

底层都是char数组，String不可变，因为类final，char数组final，StringBuilder可变线程不安全，StringBuffer线程安全，加了同步锁

#### 字符串拼接用“+” 还是 StringBuilder?

+的实质还是StringBuilder的append方法，拼接完再toString

#### String#equals() 和 Object#equals() 有何区别？

String重写了equals，判断对象内容相等，Object的equals的判断对象相等，直接判断引用

#### 字符串常量池的作用了解吗？

避免字符串重复创建，可new新建

## 基础进阶

## 泛型

#### Java 泛型了解么？什么是类型擦除？介绍一下常用的通配符？

T，E，K，V，?，类型擦除就是在运行时，指定的类型被擦除了，比如 `ArrayList<String>` 在运行时，可添加其他类型

#### 你的项目中哪里用到了泛型？

返回值，`Result<T>`

## 反射

#### 何为反射？

- 在运行时，可获取类的属性方法

#### 反射机制优缺点

- 优点是灵活，很多框架的实现核心就是反射，缺点是安全性和性能

#### 反射的应用场景

- 注解和动态代理

#### 注解是什么

用于修饰类、方法、属性

## 异常

#### Exception 和 Error 有什么区别？

Exception 是异常，出现了可 catch 捕获，Error 是错误，出现了没办法通过代码处理

#### Checked Exception 和 Unchecked Exception 有什么区别？

受检异常在编译时就会检查，非受检异常大多是在运行时发生的

#### Throwable 类常用方法有哪些？

printStack，getMsg，toString

#### try-catch-finally 如何使用？

try代码块，catch异常，finally最后

#### finally 中的代码一定会执行吗？

不一定，程序被终止，jvm退出

#### 如何使用 `try-with-resources` 代替`try-catch-finally`？

try（xx）代码块，catch 异常

## I/O

#### 什么是序列化?什么是反序列化?

序列化是将对象变为字节流，用于存储或传输的过程，反序列化是将字节流转为对象的过程

#### Java 序列化中如果有些字段不想进行序列化，怎么办？

transient关键字

#### 获取用键盘输入常用的两种方法

- Scanner 和 BufferedReader

#### Java 中 IO 流分为几种?

字节流和字符流，输入和输出流

#### 既然有了字节流,为什么还要有字符流?

方便在处理流的过程中对字符进行操作
