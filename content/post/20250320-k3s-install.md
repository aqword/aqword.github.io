# k3s安装

## 0x00 概述

1. 环境：2台公网机器、1台内网机器，已使用wireguard组网

内网机器为wsl，配置参考[wsl配置](./20250409-wsl-ubuntu-configuration)

```meraid

```




```bash
curl -sfL https://rancher-mirror.rancher.cn/k3s/k3s-install.sh | INSTALL_K3S_MIRROR=cn K3S_TOKEN=xxxxxx sh -s - server     --cluster-init     --tls-san=10.23.0.10     --advertise-address=10.23.0.10     --node-ip=10.23.0.10
```

k3s 配置
```yaml
cluster-init: true
#server: "https://10.23.0.10:6443"
token: "xxxxxx"
write-kubeconfig: "/root/.kube/config"
write-kubeconfig-mode: 644

tls-san:
  - 10.23.0.10
  - 10.23.0.20

advertise-address: 10.23.0.20
node-ip: 10.23.0.20
node-external-ip: 10.23.0.20

flannel-backend: host-gw

# 拉起rancher相关镜像
system-default-registry: "registry.cn-hangzhou.aliyuncs.com"

```
